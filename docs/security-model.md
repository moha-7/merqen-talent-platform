# Security Model

The public Merqen showcase contains no production credentials or original private company data.

Key application security concepts demonstrated by the core project include:

- Tenant-aware access control
- Membership-based authorization
- Granular recruitment permissions
- Company access scopes
- Job-level authorization
- Separate candidate authorization
- Protected candidate-file routes
- Environment-based privileged account bootstrap
- Server-side workflow validation

The full production-style source is not published in this showcase repository.
